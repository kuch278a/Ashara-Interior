1. SCOPE OF SERVICES & DELIVERABLES
================================================================================
The Developer agrees to develop, test, and deploy the web application and 
administrative portal according to the following specifications:

1.1. Client-Facing Public Experience
  a) Navigation & Page Architecture:
     - Continuous multi-section scroll home page layout.
     - Single-page isolated views for Home, Projects, Services, About Us, 
       Blog, and Contact.
     - Fixed real-time scroll progress indicator and adaptive backdrop-blur navbar.
     - Default luxury Dark Mode (#0A1525 sapphire, #1E4E4E teal, #C5A880 gold) 
       with Light Mode toggle capability.
  b) Hero Carousel Showcase:
     - Multi-slide architectural showcase with automatic 5.5s progress countdown, 
       keyboard navigation, and mobile touch swipe controls.
  c) Curated Portfolio & Case Studies:
     - Categorized project grid with real-time filtering (Governmental, 
       Corporate, Hospitality, Commercial, Residential).
     - Dedicated project detail view with project metadata, full galleries, 
       and architectural narratives.
  d) Services & Methodology:
     - 4-tier interactive accordion (Conceptualization, 3D Spatial Visualization, 
       Material Curation, Turnkey Execution).
  e) Editorial Journal (The Ashara Journal):
     - Architectural essays and thought-leadership articles with an interactive 
       reading modal.
  f) Client & Partner Matrix:
     - Interactive grid presenting official client logos and governmental seals.
  g) Consultation Booking & Inquiries:
     - Validated consultation booking form capturing client requirements, 
       scope, budget, and timeline.
     - WhatsApp, phone, email, and location integration.

1.2. Administrative Portal (Internal CMS)
  - Secure Firebase email/password authentication for authorized studio staff.
  - Inquiries Dashboard: Real-time management and status tracking of consultation leads.
  - Portfolio Management: Add, edit, reorder, or delete projects and manage media assets.
  - Journal/Blog Management: Draft, edit, and publish architectural articles.
  - Resilience & Offline Handling: Graceful fallback to local storage / default datasets.

1.3. Technical Stack & Infrastructure
  - Frontend: React 18, Vite 5, Tailwind CSS 3, Lucide React, Google Fonts.
  - Backend/Cloud: Google Firebase (Firestore, Storage, Authentication).
  - CI/CD: Automated deployment pipeline via GitHub Actions to GitHub Pages / hosting.
