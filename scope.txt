================================================================================
                        PROJECT SCOPE DOCUMENT
                           ASHARA INTERIORS
================================================================================

1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
Ashara Interiors is a premier digital platform and administrative content
management system for a luxury interior architecture and design studio based in
Ethiopia. The platform showcases high-profile governmental headquarters, corporate
head offices, presidential suites, broadcasting hubs, and bespoke residential
projects. It functions as an editorial portfolio, digital brand showcase, and 
client acquisition / lead-generation engine.


2. PROJECT OBJECTIVES
--------------------------------------------------------------------------------
- Brand Elevation: Position Ashara Interiors as a premier architectural atelier
  blending Ethiopian civic heritage with contemporary luxury standards.
- Portfolio Showcase: Present high-resolution architectural projects with case
  studies, categorized galleries, and architectural specifications.
- Lead Generation: Capture qualified client consultation bookings and project
  inquiries through interactive forms and direct contact channels.
- Dynamic Content Administration: Provide an administrative portal (CMS)
  allowing studio staff to manage project listings, journal articles, and
  incoming client inquiries.
- High Performance & Responsiveness: Deliver a fast, responsive, accessible
  web application with dark/light themes.


3. IN-SCOPE DELIVERABLES & KEY FEATURES
--------------------------------------------------------------------------------

3.1. Public User Experience (Client-Facing)
  a) Navigation & Architecture:
     - Dual navigation model: Continuous multi-section scroll on the Home Page
       and isolated single-page views (Projects, Services, About, Blog, Contact).
     - Fixed real-time scroll progress indicator and adaptive backdrop-blur navbar.
     - Default Luxury Dark Mode (#0A1525 deep sapphire, #1E4E4E forest teal,
       #C5A880 gold accents) with light mode toggling.

  b) Hero Carousel Showcase:
     - Multi-slide architectural carousel with automatic countdown timer pills,
       keyboard navigation (Left/Right arrows), and touch swipe gestures.

  c) Curated Portfolio & Case Studies:
     - Dynamic project grid with real-time category filtering (Governmental,
       Corporate, Hospitality, Commercial, Residential).
     - Dedicated Project Detail view featuring project metadata (location,
       year, scope, client), full image galleries, and design narratives.

  d) Services & Methodology:
     - 4-tier interactive accordion detailing studio methodologies:
       1. Conceptualization & Spatial Planning
       2. 3D Architectural Visualization
       3. Material Curation & Procurement
       4. Turnkey Execution & Project Supervision

  e) Editorial Journal (The Ashara Journal):
     - Architectural essays and thought-leadership articles with an interactive
       reading modal.

  f) Client & Partner Matrix:
     - Interactive grid displaying 15+ verified governmental seals, ministries,
       and enterprise client logos.

  g) Consultation Booking & Inquiries:
     - Interactive consultation booking form capturing client requirements,
       project scope, estimated budget, timeline, and contact information.
     - Direct communication channels (WhatsApp, Phone, Studio locations).

3.2. Administrative Portal (Internal CMS)
  - Authentication: Secure Firebase email/password login for studio administrators.
  - Lead Management: Real-time dashboard for reviewing, filtering, and updating
    inquiry statuses (New, Contacted, In Progress, Archived).
  - Portfolio Management: Add, edit, reorder, or delete projects and manage media assets.
  - Journal/Blog Management: Draft, edit, and publish architectural articles.
  - Resilience & Offline Support: Seamless fallback to local storage / pre-configured
    datasets when offline or without live Firebase credentials.


4. TECHNICAL ARCHITECTURE & STACK
--------------------------------------------------------------------------------
- Frontend Framework: React 18
- Build Tooling & Dev Server: Vite 5
- Styling & Design System: Tailwind CSS 3 (custom luxury design tokens)
- Iconography: Lucide React
- Typography: Google Fonts (Cormorant Garamond, Plus Jakarta Sans, Pinyon Script)
- Backend & Cloud Storage: Google Firebase (Cloud Firestore, Storage, Auth)
- CI/CD & Deployment: GitHub Actions pipeline deploying to GitHub Pages


5. OUT-OF-SCOPE (CURRENT PHASE)
--------------------------------------------------------------------------------
- E-Commerce & Checkout: Online retail payment gateway for direct furniture sales.
- 3D WebGL / Virtual Reality: In-browser 3D walkthrough engines (Three.js/Matterport).
- Multi-Language Localization (i18n): Amharic and multi-language switching
  (deferred to future milestones).
- Client Milestone Dashboard: Real-time construction Gantt charts / live site cameras.


6. SUCCESS CRITERIA
--------------------------------------------------------------------------------
- Fully responsive, cross-browser compatible application deployed to production.
- Sub-2 second load times for public asset delivery.
- Operational consultation submission pipeline capturing qualified leads.
- Functional administrative portal for managing dynamic site content.
